                                                     **   FREERTOS TEMPLET  **
------------------------------------------------------------------------------------------------------------------------------------

This project is built using CMake and is tailored for the Raspberry Pi Pico 2 W (RP2350 architecture) using the official Pico C/C++ SDK and FreeRTOS.
It is also fully compatible with the official Raspberry Pi Pico VS Code extension.

Hardware Target
Board: Raspberry Pi Pico 2 W (pico2_w)

Architecture port: RP2350_ARM_NTZ (Non-TrustZone FreeRTOS port)

Toolchain & SDK
CMake Minimum Version: 3.13

Pico SDK Version: 2.3.0

ARM Toolchain: 15_2_Rel1

Picotool Version: 2.3.0

Language Standards: C11, C++17
